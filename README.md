### Projeto: Site Oficial da ONG Lar Amigo 🐾

Este repositório contém o código-fonte desenvolvido para a ATPS de Design para Web, contemplando a criação do site responsivo para a ONG fictícia **Lar Amigo**.

#### Estrutura de Arquivos:
- `index.html`: Página inicial com missão, ações e depoimentos.
- `adote.html`: Galeria de fotos de cães e gatos disponíveis para adoção.
- `contato.html`: Formulário de contato, voluntariado e doações via PIX.
- `css/style.css`: Folha de estilo com reset, CSS Grid, Flexbox e @media queries para responsividade.
